# Web 视觉整合第一开发阶段任务单

状态：建议任务，尚未执行。日期：2026-10-08。前置交付：[架构审计与页面映射](../audit/web-visual-integration-v1/report.md)。本文件不将后续开发阶段一次性授权给执行代理。

## 主要目标

在 xsj-content-center 的同一 Next.js 架构中建立隔离评审入口，原创重新设计烟熏光学玻璃星球首页、通用导航外壳、可折叠资源栏和 Visual Lab，先形成真正可体验的产品形态。保留 Mineradio 的空间层次、悬浮功能层、深色舞台和镜头反馈思想；不以之前生成的宇宙/贴图/SaaS 布局为设计基础，不移植参考项目源码或资源。

## 本地源码接续

1. 以 `D:/Documents/ChatGPT/内容生产中心-integration` 的最新实际源码为业务参考，再核对 `inventory.json`。GitHub 默认分支是旧审计版本，不从它恢复业务。
2. 施工前冻结完整白名单源码及必要未跟踪文件到独立施工工作区，记录路径、分支、HEAD、manifest 与差异。审计分支只有文档，不能直接当完整最新代码快照。
3. 所有施工在独立 `codex/` 分支，保留回退到原运行版本和原页面的入口。未经新任务授权，不暂存、提交或推送。
4. 当前 3000 服务、身份数据库、附件、凭据、迁移和真实业务数据保持原有运行方式。预览使用独立 Web 端口与清楚的演示标识。

## 范围

- 首页：原创玻璃星球、细星轨、低密度粒子、空间深度；最近项目、今日任务、工作入口使用明确 fixtures，长列表不能充斥舞台。
- 顶部：品牌、工作区操作、独立老板入口、外观入口。老板真实能力未接入时明确说明。
- 左侧：IP、项目、最近任务，支持折叠与键盘访问；首页首次收起、工作页首次展开、后续尊重偏好。
- Dock：首页、研究、创作、内容、复盘，固定五项。演示入口切换示例页面/状态，不在真实服务失败时用假数据兜底。
- 右侧：按示例任务显示 AI 辅助状态；现阶段不发送真实对话和不伪造真实生成成功。
- Visual Lab：玻璃材质、轨道、光照、粒子、动画、界面参数即时预览。个人预设与本机公司草案可保存、恢复、导入导出；公司服务端发布标记未接入。
- 普通外观仅给必要简易设置。高级预览与 Visual Lab 访问在服务端保护，可复用现有系统管理员边界；不能用查询参数/localStorage 赋予权限。
- 3D 为独立客户端叶子；关闭、暂停、后台暂停、降质、减少动态、WebGL 初始化失败/上下文丢失时的原创替代展示均可体验。

## 允许复用与禁止扩张

复用真实业务的类型契约、资源组织状态机、参数验证能力、通用图标、Button 与已有权限 helper。UI 的新空间构图、材质、轨道、布局和动效原创重做。

不更改 Project/Artifact/Research/Skill 的业务模型，不把私人稿件并到公共资产，不改写保存/版本/会话服务，不把平台内容审核解释为表现复盘。现阶段不重做业务内页、后端、数据库或正式驾驶舱数据，不合并第二套系统。

先检查并声明 Three、R3F、Drei、GSAP 的实际依赖、锁文件、兼容和许可证，再按必要性安装。候选宇宙分支的版本只是可调查信息；本任务不沿用它的既有视觉设计。

## 动态浏览器验收

| 验收项 | 操作与可判定结果 |
| --- | --- |
| 材质与空间 | 1920×1080、1440×900 查看玻璃透射/烟熏深度、细轨道、低密度粒子；连续观察与镜头操作。普通行星贴图或背景图不通过此项。 |
| 导航与布局 | 实际切换五项 Dock、折叠侧栏、打开/关闭抽屉、进入示例工作页；没有重复导航、遮挡或不可达按钮。 |
| 参数即时反馈 | 连续拖动玻璃/光照/轨道/粒子参数，变化同步且不锁住 UI。 |
| 预设 | 调整、保存个人预设、刷新、恢复、重置、导出/导入；坏 JSON/越界参数/存储不可用显示真实错误并保留当前可用状态。 |
| 权限 | 未登录和无管理权限无法读取高级预览内容；普通外观不会出现公司发布权限。 |
| 降级 | 暂停、关闭、低质量、后台、减少动态、模拟 WebGL 不可用与上下文丢失；导航与正文仍可用。 |
| 演示边界 | 标识为演示；点击未实现操作显示状态，提交/保存不会生成假真实成功；没有调用真实采集、AI 或写入业务内容。 |
| 业务回归 | 当前首页创建入口及项目、研究、稿件、资料、设置旧入口仍可到达；类型检查、受影响组件与权限检查通过。 |

交付独立可运行 Web 地址、1920/1440 截图、动态交互操作记录、代码 diff、当次测试结果与未完成项。截图仅为证据的一部分，编译或静态截图不能替代浏览器动态评审。第一阶段交付后先验收，再接下一阶段任务。
