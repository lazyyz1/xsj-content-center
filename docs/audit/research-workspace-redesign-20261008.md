# 研究工作区重设计（2026-10-08）

## 目标与已发现的问题

用户授权整个研究页面重设计，沿用已经确认的能力与真实数据。实际账号页保存了 20 条作品，但默认最近 30 天过滤后展示 0 条；首屏以学习目的、同步、统计说明为主，阅读内容被挤到后面。研究子导航有六个并列入口，作品详情同时存在作品侧栏和应用导航。

本轮以内容阅读为主要任务，合并入口与调整默认行为。不修改 PRODUCT / ARCHITECTURE / LEGACY / AGENTS，不迁移数据库，不添加假报告，不启用付费服务。

## 拆解与采用

结构名称继续来自保存的报告，不套固定“钩子—背景—案例”模板。段落原文、引用依据、表达观察和未验证的作用假设分开呈现。没有可靠时间码时显示原文顺序，不估计镜头或时长。

采用沿用既有显式选择与项目交接。研究页可直接返回创作入口，无需先研究或填定位。当前交接仍进入既有项目待发送输入；本轮没有实现创作任务独立 threadId，不能将导航改版描述为已完成独立创作。

## 首版接下来的分配

1. 创作工作区：在长期项目内实现每条创作任务独立对话、草稿和稿件版本，采用的结构在旁边可见。先完成数据和权限隔离，再调整创作页面。
2. 单条内容进度：围绕同一条内容补充待拍/已拍、关联成片、手动发布状态与数据记录，支持手动交接稿件。
3. 复盘：单条复盘属于内容详情；跨视频总览单独保留。无需为了模块齐全反复跳转。
4. 自动剪辑、自动打包、自动发布和平台日历联动单独评估；不由参考视频入口推定为已实现或本轮必做。

不沿用旧 20–24 天估算承诺。本轮依据用户提供的关键画面拼图、明确需求、实际网页和源码核对；未重新转录参考视频音轨。
