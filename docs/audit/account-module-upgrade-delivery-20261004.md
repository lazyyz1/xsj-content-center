- 认证：开发和正式运行均显式启用限流。复用Verification存储哈希后的计数键，并以事务advisory lock原子计数，无Redis或新表。当前回环运行不信任客户端伪造的转发IP；额外按操作和账号限制。登录账号不存在/密码错误等公开响应统一；数据库异常返回安全服务失败。
- 来源：管理员创建/停用接口复用成员/设置的来源校验；拒绝外部/opaque Origin、cross-site和简单内容类型伪造JSON。服务端身份、Workspace与角色检查仍保留。
- 停用：全局登录账号与空间成员资格分别展示；平台停用账号不能通过恢复成员资格获得登录，服务端拒绝假恢复。系统管理员/自己仍不能经普通流程停用。全局停用还保护最后有效OWNER及最后有效管理员；同空间治理写入串行化。
- 创建和交接：内部用户、credential、个人空间与审计同一事务；客户首版为平台开空白公司空间、负责人邮箱邀请，平台人员不会自动成为客户成员。交接仅当前OWNER可执行，目标必须是本空间有效成员，原OWNER保留ADMIN；跨空间和竞争交接被拒绝。未对真实数据执行这些操作。
- 恢复/验证/邀请：复用Verification实现短期、高熵、一次性挑战；数据库只保存挑战摘要。恢复20分钟、邀请48小时；限制邮箱匹配、旧身份本人登录、停用账号、重放、过期、撤回与角色升级。恢复撤销全部会话且不自动登录、不恢复账号或成员资格；邀请不重置已有账号密码。邮件失败撤回邀请，不虚报已发送。
- 会话/审计：退出其他设备保留当前会话并核对归属；改密、恢复、验证、邀请、交接与设备退出记录安全事件。无Workspace用户的账户事件暂存于独立Verification命名空间，90天有效期，并非永久企业审计档案；事件不保存密码或原始凭证。
- 前台：恢复与邀请页面、邮箱服务提示、待接受邀请列表/撤回、平台客户空间元数据与无人空间提示；重复点击锁、断网恢复、加载/空态、字段标签和确认密码焦点。callback凭证只在组件内存使用，清除URL fragment时保留Next导航状态，不展示token或存入浏览器存储。320px设置改为分类选择器，保留表单宽度；设备时间明确为会话更新而非实时在线。
- 无空间平台入口：/platform/accounts 与 /platform/spaces 按服务端SYSTEM_ADMIN校验独立于客户成员资格。普通账号不能使用；平台身份不能因此读取客户项目内容。现有账号管理页和无可用空间页可发现入口。
