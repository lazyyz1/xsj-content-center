# 测试版上线问题清单（2026-09-28）

范围：Render `xsj-content-web-free-staging`，已核对其运行版本为 `101da458`，分支 `codex/web-experience-stable`。这是一份当前状态记录，不把本地实验代码视为线上功能。

## 已确认的问题

| 优先级 | 问题与证据 | 对测试的影响 | 收口条件 |
| --- | --- | --- | --- |
| P0 | 线上仅有免费 Web 服务，没有队列消费者。两条线上视频资料的采集任务均为 `QUEUED`，资料 `PENDING`，没有转写任务或文字稿。 | 链接采集、视频播放和豆包转写无法完成。 | 有实际执行队列的进程；用真实 MP4 跑通保存、播放、转写、刷新恢复。若本轮不提供，入口需明确不可用并停止让任务无限排队。 |
| P0 | 免费 Web 无持久磁盘；Render 官方说明其本地文件会在重启、休眠或重新部署后丢失。数据库中的文件记录可能仍保留。 | 上传原件及视频预览无法保证恢复，可能出现就绪资料没有原件。 | 使用持久媒体存储并做重启恢复测试，或明确本版只演示不依赖文件保存的流程。 |
| P1 | 共享体验账号的访客会看到同一空间的项目、聊天和文件；这是已接受的体验范围。自动清理“三天后删除内容”仍未实现。 | 使用者可能互相看到内容，上传与生成内容会超出约定保留时间。 | 仅用公开示例、明确展示共享属性；实现按72小时清理数据库记录与媒体对象，或撤下三天承诺。 |
| P1 | 免费 PostgreSQL 有30天有效期；当前站点仍使用免费库。 | 测试期延长时账号、项目与成果存在中断风险。 | 核对实际到期日期，提前备份或确定新环境承载。 |
| P1 | 免费 Render Key Value 无磁盘持久化，重启后队列和体验额度计数会丢失。 | 排队任务可能留在数据库却没有消费者记录；用量限制可能重置。 | 在免费演示范围内明确说明并让失联任务终结；额度改用可恢复的记录核算。 |
| P1 | 用量限制按账号和空间计数，五个访客共用 `xsj666` 时共享同一额度；配置说明中“每位访客”的口径不准确。研究/发现 API 的全部付费入口也未做统一额度核对。 | 多人测试可能提前耗尽额度，或产生不可预测的第三方调用。 | 给共享账号明确总额度、并发和提示；核对 RedFox、DeepSeek、豆包的入口覆盖与服务商余额。 |
