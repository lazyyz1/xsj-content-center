# 拆解详情：参考布局还原

本次优先范围由用户明确指定为“先还原拆解的详情页面”。对照所提供的第 5–10 张参考图，恢复报告列表、作品摘要与指标、主线结构、解释区之间的关系。继续沿用全站灰白紫主题，主色 `#7258f5`。

## 本次修改

- 左侧显示已完成报告，可直接切换；每条作品取最新可见报告，历史版本由阅读区选择。窄屏折叠列表，仍可以展开切换。
- 顶部白色作品卡显示账号、标题、发布日期、已知时长及六项指标；借用结构是主动作，部分结论选择和保存/分享收进“更多”。分享仍须明确选择，不更改私人可见范围。
- 中间左侧先显示一句话主线，再按原内容显示结构段落。无可靠时间码时显示紧凑的结构顺序条，不冒充时间轴。有真实时间码时显示时间轴，并沿用原视频定位能力。
- 中间右侧集中显示表达观察、引用依据、对应段落和作用假设。同一分析不因对应多个段落重复展开。
- 每段默认显示本版报告的内容决策，保留可展开原文及单段结构采用。已有核心写法和承诺兑现缺口在结构、分析区可见，不改写研究记录。
- 桌面宽度至少 1100px 且高度至少 650px 时，根据报告所在位置计算可用高度；作品摘要与指标留在顶部，正文与右侧分析在一个阅读区域中滚动。原文/视频、研究操作通过视图切换查看；左侧列表另有自己的滚动区域。手机和低高度窗口顺序阅读。
- 读取历史版本时，标题、原文、互动指标及采用的结构属于该版本快照；同账号比较明确使用当前已保存样本。原视频仅在与显示的证据一致时联动，不用当前视频替代历史资料。
- 助手打开后收起报告列表，在较窄的桌面空间中顺序展示正文与分析，保留当前报告对象绑定。
