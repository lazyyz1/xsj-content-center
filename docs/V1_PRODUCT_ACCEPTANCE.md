## V1 happy path

使用页面创建并完善 Creator A，随后仅通过产品 UI 完成：

1. 登录并进入工作台。
2. 收录测试文本，等待后台处理完成。
3. 在素材详情添加标签并创建内容项目。
4. 在创作工作台添加观点 / 证据并生成、编辑、保存创作简报。
5. 在 `MOCK MODE` 生成并保存深度创作包，检查选题、观点、证据边界、表达素材、结构方案、创作者资产与风险。
6. 生成 GPT 创作任务包，复制给 GPT，人工模拟 GPT 网页成稿后导入为新的核心母稿。
7. 生成并人工应用抖音、小红书、朋友圈、视频号、公众号五个平台版本。
8. 将公众号版本提交审核，运行可选 AI 检查，填写人工审核意见并批准。
9. 加入发布中心，设置计划时间，复制完整发布包。
10. 填写内部试用链接和“未连接真实平台”的备注，由人工标记为已发布。

结果：主链路通过；AI 没有代替人工审批，发布也没有触发真实外部动作。

## P2

本阶段已顺手处理的明显 P2：

- 素材库平台、类型、状态和素材集文案中文化。
- 设置首页按个人创作、AI 与外部服务、团队权限重新命名。
- 深度创作包的主要内容模块改为中文标题。
- 平台内容中的 Hook / Hashtags 可见标签改为“开场 / 话题标签”。
- `MOCK` 徽标统一为醒目的 `MOCK MODE`。

仍保留的 P2：

- CreatorProfile 表单仍较长，后续可增加分组导航，但不影响填写和保存。
- 月历在窄屏以完整七列呈现，功能可用但阅读密度仍高。
- 本地开发环境仍会请求缺失的 `/favicon.ico`，不影响业务流程。
- 静态 `MOCK MODE` 深度创作包不会复刻真实模型的上下文理解；它保持显式模拟标识，不冒充真实结果。
